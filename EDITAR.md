# Cómo editar el portfolio

El contenido visible se encuentra dentro de la carpeta `content`.

- `_home.qmd`: presentación, título principal y áreas de trabajo.
- `_projects.qmd`: proyectos y enlaces.
- `_experience.qmd`: experiencia, métodos y herramientas.
- `_publications.qmd`: publicaciones.
- `_contact.qmd`: contacto y pie de página.

## Modificar un texto

1. Abrir el archivo correspondiente en GitHub.
2. Presionar el botón del lápiz.
3. Cambiar solamente el texto entre las etiquetas. No modificar expresiones como `<section>`, `<div>`, `class=` o `id=`.
4. Presionar **Commit changes**.
5. Esperar unos minutos mientras GitHub vuelve a publicar el sitio.

## Reemplazar el CV

Reemplazar `files/Maria_Eugenia_Romero_CV.pdf` por el nuevo PDF usando exactamente el mismo nombre.

## Reemplazar la ilustración

Reemplazar `images/grasshopper-fish.png` por la nueva imagen usando exactamente el mismo nombre.

## Ver el estado de publicación

La pestaña **Actions** del repositorio muestra si la actualización terminó correctamente. El sitio se publica en `https://eugerom.github.io`.
